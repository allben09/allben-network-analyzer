# 🛡️ allben-network-analyzer

## 🔍 Overview
**allben-network-analyzer** is an advanced network traffic analysis tool built by **Allben Rakgoale**. It captures live packets, analyzes protocols, and uses **Machine Learning** to detect anomalies like ARP spoofing, port scanning, and DDoS patterns.

## 🚀 Features
- **Live Packet Capture** – Real-time sniffing using Scapy.
- **ML-Powered Detection** – Isolation Forest model to spot network anomalies.
- **Interactive Dashboard** – Visualize traffic, protocols, and threats instantly.
- **Docker Ready** – Run it anywhere with a single command.

## 🛠️ Tech Stack
- **Language**: Python 3.11
- **Libraries**: Scapy, Pandas, Scikit-Learn, Streamlit
- **ML**: Isolation Forest (Anomaly Detection)
- **DevOps**: Docker, GitHub Packages
