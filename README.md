## 🔍 Overview

**allben-network-analyzer** is a production-grade network traffic analysis framework that combines **packet sniffing**, **protocol analysis**, and **Machine Learning-based anomaly detection**. Built by **Allben Rakgoale**, this tool is designed for cybersecurity professionals, network administrators, and security researchers.

### 🎯 Key Capabilities

| Capability | Description |
| :--- | :--- |
| **Real-Time Packet Capture** | Non-intrusive packet sniffing using Scapy |
| **Protocol Analysis** | Deep inspection of TCP, UDP, ICMP, and more |
| **ML Anomaly Detection** | Isolation Forest model for identifying suspicious traffic patterns |
| **Threat Identification** | Detects port scanning, DDoS patterns, ARP spoofing, and malicious IPs |
| **Interactive Visualization** | Real-time dashboard with traffic metrics and threat alerts |
| **Dockerized Deployment** | Containerized for easy deployment in any environment |
